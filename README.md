# t5_visao
Testes da rede neural MLP no iris-dataset

## Overview
Computer Vision course exercise: a **Multi-Layer Perceptron implemented from scratch with NumPy** (adapted from a public Kaggle notebook), trained and tested on the Iris dataset. The notebook `NN_scratch_irirs_TA05.ipynb` loads and shuffles the data, explores it (histograms, scatter matrix), splits train/test, implements the MLP class (forward pass, backpropagation) and evaluates it.
